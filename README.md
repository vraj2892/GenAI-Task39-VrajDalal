# GenAI Code Assistant

A Streamlit-based Generative AI application that helps users:

- Generate Python code
- Explain existing code
- Debug potential errors
- Suggest code improvements

The application uses a hosted language model API.
The API key is configured as a Space secret and is
not stored in the source code.
